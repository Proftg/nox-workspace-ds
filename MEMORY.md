## 🚉 VOCABULAIRE MÉTIER SNCB/INFRABEL

| Terme | Définition |
|---|---|
| **Ponctualité brute** | % de trains arrivés avec < 6 min de retard |
| **Ponctualité pondérée** | Même calcul pondéré par le nombre de voyageurs |
| **Reliability** | Taux de trains non annulés |
| **Minutes perdues** | Somme totale des minutes de retard — impact économique |
| **Sillon** | Plage horaire réservée sur l'infrastructure pour un train |
| **Neutralisation** | Fermeture temporaire d'une voie pour travaux |
| **Jonction N-M** | Jonction Nord-Midi à Bruxelles — goulot d'étranglement principal |
| **Contrat de Performance** | Accord État-Infrabel sur les objectifs de ponctualité |

**Formulation entretien clé :**
> "J'ai calculé le taux de ponctualité brute (trains avec moins de 6 minutes de retard) et les minutes perdues totales pour quantifier l'impact économique — les deux KPIs principaux du Contrat de Performance d'Infrabel."
